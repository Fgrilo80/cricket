# Cisco Quiz (CCST / CCNA / CCNP / Cybersegurança)

As perguntas já não vão dentro do HTML. Cada certificação e língua é um ficheiro em `data/`.

## Abrir no PC
Abre `index.html` no browser (duplo clique). Precisas da pasta `data` ao lado do HTML.

## Acrescentar perguntas
Edita o ficheiro certo, por exemplo `data/ccna-pt.json` (e o `.js` correspondente).
Também existe `data/cyber-pt.json` / `data/cyber-en.json` para o 4.º trilho.

Formato de cada pergunta:
{
  "question": "Pergunta?",
  "options": ["A", "B", "C", "D"],
  "correct": 0,
  "explanation": "Porque é a A.",
  "difficulty": "Fácil"
}
`correct` é o índice da opção certa (0, 1, 2 ou 3).

Para abrir no telemóvel a pasta tem de estar num servidor (mesmo Wi-Fi) ou publicada na web.
